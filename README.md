# suptelia.brows

Сайт майстра брів **suptelia.brows**: прайс, бренди, фото робіт, фото до/після, відгуки, про майстра, відео і карта, контакти, міні-бот з відповідями на питання і прихована адмінка.

## Як відкрити адмінку

Натисніть **4 рази поспіль** на логотип у шапці.

- Вхід за поштою і паролем власниці, які створено в Supabase (Authentication → Users). Пароль ніде в коді не зберігається.

В адмінці:
- **Шаблони**: до/після в колах, до/після з овалом, звичайне фото з колом «крупний план». Фото підганяються повзунками, результат одразу видно.
  - «Опублікувати на сайті» додає картку на сайт.
  - «Зберегти для сторіс» завантажує PNG 1080×1920.
- **Публікації**: перегляд і видалення доданого.
- **Відгуки**: 3–5 зірок публікуються одразу, 1–2 зірки чекають перевірки; будь-який відгук можна сховати або видалити.
- **Прайс** і **Про нас**: редагування тексту і цін. Міні-бот бере ціни звідси.

## Структура

```
index.html          сторінка
css/style.css       стилі
js/config.js        налаштування: Supabase, адреса, контакти
js/store.js         дані: localStorage (тест) або Supabase
js/bot.js           міні-бот
js/app.js           логіка сайту і адмінки
js/vendor/          бібліотека Supabase (MIT), лежить у репозиторії, без стороннього CDN
assets/             фото, відео, шаблони
supabase/schema.sql          таблиці і правила доступу для Supabase
supabase/security-update.sql тригер відгуків, антиспам, ліміти сховища
```

## Запуск локально

Відкрийте `index.html` через будь-який локальний сервер, наприклад у VS Code розширенням Live Server. Шаблони в адмінці потребують сервера: з подвійного кліку по файлу кнопка «Опублікувати» не спрацює через обмеження браузера.

## Публікація на GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → гілка `main`, папка `/ (root)` → Save. За хвилину сайт буде доступний за адресою `https://<ваш-логін>.github.io/suptelia-brows/`.

## Підключення Supabase

Сайт можна додати і в окремий проєкт, і в уже наявний: усі таблиці мають префікс `suptelia_`, а бакет для фото називається `suptelia-posts`, тож вони не змішаються з іншими даними.

1. Відкрийте проєкт на [supabase.com](https://supabase.com). Якщо він на паузі, натисніть **Resume project**.
2. SQL Editor → вставте вміст `supabase/schema.sql` → Run, потім так само `supabase/security-update.sql`. Обидва файли можна запускати повторно.
3. Authentication → Users → Add user: пошта `margoesterhazi@gmail.com` і пароль. Пошту треба підтвердити: адміном сайту вважається тільки користувач з підтвердженою поштою.
4. Project Settings → API: скопіюйте **Project URL** і **anon public key** у `js/config.js`.

Після цього публікації, прайс і відгуки зберігаються в базі, і всі відвідувачі бачать однакові дані.

## Захист

- **Права в базі.** Усі права перевіряє сама база Supabase (Row Level Security). Змінювати прайс, фото й відгуки може лише користувач з підтвердженою поштою `margoesterhazi@gmail.com`. Прихована адмінка на сайті — це лише зручний інтерфейс, а не захист.
- **Відгуки.** Сервер сам ставить статус (3–5 зірок одразу, 1–2 на перевірку) і дату, обрізає пробіли й обмежує довжину. Діє ліміт: не більше 10 відгуків за 10 хвилин на весь сайт. У формі є пастка для ботів і пауза в 1 хвилину між відгуками.
- **Сховище.** Приймає лише JPEG і PNG до 5 МБ.
- **Сторінка.** Політика безпеки (CSP) дозволяє скрипти тільки з самого сайту. Увесь текст від відвідувачів виводиться як текст, не як HTML.
- **Ключі.** У коді лише публічний `anon`-ключ. Секретні ключі, токени й паролі в репозиторій не додавайте.
